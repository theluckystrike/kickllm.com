Claude cost calculators audited, 4 of 9 print a cancelled rise

By Michael Lip, who builds and operates KickLLM. More about the author.

Every figure captured 29 August 2026. The pages measured can change at any time, so treat each reading as a dated snapshot, not a verdict on the site today.

We fetched nine Claude cost calculators that rank for this topic on 29 August 2026 and compared every Claude price they display against two independent sources read the same day, the Anthropic pricing page on platform.claude.com and the OpenRouter models API. Four of the nine still tell readers that Sonnet 5 rises to $3 / $15 on 1 September. A fifth, vortenza.com, prints $3 / $15 as today's Sonnet 5 rate with no date attached. Anthropic's own page, fetched at 10:01 UTC that morning, says: The $2/$10 per million input/output token pricing for Claude Sonnet 5, announced at launch as introductory pricing through August 31, 2026, is now the standard price. The previously scheduled increase to $3/$15 per million input/output tokens on September 1, 2026 will not occur. Two of the nine display a wrong current-generation price. The widest gap is vortenza.com, which prints Opus 5 at $15 / $75 against a corroborated $5 / $25, a 3x gap on both input and output. Two of the nine list no Claude 5 model at all. Only benchlm.ai and calculatequick.com surface the 1-hour cache write tier that sits in Anthropic's own table.

Seven of nine matched both sources on every comparable row. Only one of those, aicodex.to, did so without also printing the cancelled September increase or dropping the Claude 5 family entirely. A correct table can still lead a reader to the wrong budget when the prose around it has expired.

How we measured this

We fetched two sources on 29 August 2026 at 10:01 UTC, the Anthropic pricing page in both its markdown and HTML forms, and the OpenRouter models API. A rate is corroborated when both sources agree. They agreed exactly on every model both carry. Mythos 5 is not listed on OpenRouter, so its one comparison is against Anthropic alone. Nine calculator pages were then fetched by curl between 10:01:43 and 10:01:48 UTC, and each capture's byte count and SHA-256 are recorded. A tenth page, the pricepertoken.com provider page, returned HTTP 404, so we replaced it with that site's Opus 4.7 token counter page, which carries the same model table. We quote every price as the raw text around the model name in the served HTML, at a recorded byte offset. A displayed rate counts as differing when it moves away from the corroborated pair on a model both sources carry. Rates are USD per 1M tokens. Cache, batch and context columns were not scored. The feature flags in the embedded data, such as cache write or tokenizer, are keyword hits in the page text and were not tested by use. The full per-site readings are embedded in this page's source as JSON.

What to do

Read the price from the vendor before you trust a calculator. The Anthropic pricing page carries base input, 5-minute cache write, 1-hour cache write, cache read and output for every model, and the note that cancels the Sonnet 5 increase. The OpenRouter models API is a second independent read of the same rates. On this site the Claude API pricing page holds the snapshot rates we corroborated, and the LLM cost calculator turns a token count into money from those rates. The same audit method was run on OpenAI calculators, see how accurate OpenAI cost calculators are, and the cases where public sources disagree with each other are on the price source disagreement page.

Why calculators drift

Two patterns cover every gap in the readings. The first is an announcement that outlived its correction. Sonnet 5 launched with a $2 / $10 rate described as introductory through 31 August 2026. Four pages repeat that framing and the $3 / $15 standard rate that was to follow. Anthropic then made $2 / $10 the standard price and said the increase will not occur. The four pages carried the old sentence at capture, and one of them, benchlm.ai, is labelled as of 29 August 2026, the same day we read the correction. The second is a table that was built for one generation and never grew. flowlyn.com stops at Opus 4.6. techsy.io stops at Opus 4. vortenza.com has a Claude 5 section but prints Opus 5 and Opus 4.7 at the $15 / $75 Anthropic lists for the retired Opus 4.1, and Haiku 4.5 at the Haiku 3.5 rate.

A date label did not predict accuracy in this set. The freshest label, pricepertoken.com at 28 August, sits on a page with a wrong Mythos 5 row. The clean page, aicodex.to, is labelled 21 August. Find the date, then check one flagship rate against the vendor. If the flagship is wrong, close the tab.
