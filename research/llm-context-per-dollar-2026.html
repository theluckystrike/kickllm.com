Context Window Per Dollar Index 2026

Published September 30, 2026 · 434 models · Updated quarterly

DeepSeek V4 Flash Latest gives you about 109 million context tokens per dollar of input spend. GPT-4 gives you 273. We pulled all 434 models on OpenRouter, divided each model's context window by its input price, and ranked the results.

The ratio answers a narrow question: how much prompt can you feed a model per dollar? If your workload is input-heavy (RAG, long-document analysis, big system prompts), it is the single most useful price metric. Output pricing is a separate problem. See the OpenRouter pricing calculator for blended estimates.

Methodology

  • Dataset: 434 model variants listed on OpenRouter, September 2026. Fields used: context window (tokens), input price (USD per 1M tokens).
  • Ratio = ctx tokens ÷ input price per $1. The main table shows ctx-tokens per $1,000 input budget = ctx × 1000 ÷ in.
  • Median ratio across all 434 models: 638,260 ctx-tokens per $1 (about 638M per $1,000).

Caveats: input price only. Output tokens usually cost 3–10x more and are excluded here. Context windows are as advertised by the provider; effective usable context can be smaller due to degradation past ~128K tokens on many models. Batch-tier variants (:batch, 50% discount) and “latest” aliases appear as separate rows, which is why some models show up twice. Prices change frequently; verify current rates before committing.

What stands out

The leaders are all budget-tier Chinese open-weight models with 1M+ contexts priced under $0.03/M. DeepSeek V4 Flash Latest at $0.012/M with a 1.31M window is roughly 800x better value than GPT-4, which still sells at legacy pricing. GLM Flash Latest and the Qwen flash models cluster in the 33–65M range.

The losers are legacy. GPT-4, GPT-3.5 variants, and o1-pro earn their spots through small windows, $30–$150/M pricing, or both. Nobody should be buying these in 2026 except for compatibility.

Batch tiers punch above their weight. GPT-6 Luna at $0.05/M via batch delivers 21B ctx-tokens per $1,000, double the standard tier at $0.10/M. If your workload tolerates 24-hour turnaround, batch pricing halves the effective cost.
