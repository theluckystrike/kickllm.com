GPT-5.5 Pro Pricing — API Cost Breakdown

GPT-5.5 Pro costs $30 per 1M input tokens and $180 per 1M output tokens. The context window holds 1,050,000 tokens, and OpenAI sells a batch variant at $15/$90 for workloads that can wait a few hours. All figures below come from live OpenRouter listing data (434 models, checked September 2026).

Pricing overview

MetricValue

ProviderOpenAI

Output tokens drive the bill here. At a typical 4:1 input-to-output ratio, output costs are about six times the input spend, so prompts that generate long answers will hurt more than long prompts. The $180 output rate is the highest OpenAI currently lists outside the retired o1-pro.

GPT-5.4 Pro lists at the exact same rates and context size, so the two are interchangeable on price alone. Claude Opus 4.1 undercuts GPT-5.5 Pro on both rates, though its 200K window can't hold the million-token documents GPT-5.5 Pro swallows in one pass.

Batch discount math

The batch API pays half price on both directions. Input drops from $30 to $15, output from $180 to $90. No minimum volume, no tiered schedule, just 50% across the board.

The catch is latency. Batch requests complete within 24 hours, so this only works for overnight backfills, report generation, evaluation runs, and anything else that isn't user-facing. For interactive traffic you pay full price.

When GPT-5.5 Pro is worth it

  • You need to reason over documents longer than 400K tokens. Nothing else in OpenAI's current lineup holds a million tokens, and re-chunking a huge doc into a cheaper model usually costs more than the premium.
  • The task genuinely needs deep reasoning and the answer is expensive to get wrong. A single wrong legal analysis or code migration costs more than a year of the price gap versus GPT-5 Pro.
  • Your volume is low enough that the $75/month benchmark number above reads as rounding error in your budget.

And when it isn't. If your workload fits in 400K tokens and doesn't need the extra reasoning depth, GPT-5 Pro does the same job for 40% less. If it fits in 200K and quality requirements are moderate, Claude Opus 4.1 is the cheapest flagship on the board. If you're doing bulk non-urgent processing, run GPT-5.5 Pro through the batch API and cut the bill in half without switching models.

Common questions

How much does GPT-5.5 Pro cost?

$30 per 1M input tokens, $180 per 1M output tokens on the standard API. The batch variant is $15/$90.

How big is the context window?

1,050,000 tokens. That's more than double GPT-5 Pro's 400K and five times o1-pro's 200K.

Is GPT-5.5 Pro cheaper than o1-pro?

Yes, by a wide margin. o1-pro lists at $150/$600, five times the standard rates, with a fifth of the context. Unless you're locked into o1-pro for a legacy reason, GPT-5.5 Pro wins on price and window size.

What does 1M input and 250K output per month cost?

$75 on the standard API. Run the same volume through batch and it's $37.50.
