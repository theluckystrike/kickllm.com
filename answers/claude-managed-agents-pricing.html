Claude Managed Agents pricing, $0.08 per session-hour plus model tokens

Claude Managed Agents bills the tokens of a session at the model prices and the runtime of the session at $0.08 per session-hour. This page gives the two official worked examples, the modifiers that apply and a session cost calculator.

By Michael Lip · Updated 2026-10-28

Each official price on this page is from one source, the Claude Platform pricing page of Anthropic, fetched on 10 October 2026 at 08:21 UTC. Prices are USD list prices. They can change without notice. KickLLM is not affiliated with Anthropic.

Claude Managed Agents is billed on two dimensions: tokens and session runtime. All tokens that a session consumes are billed at the prices of the Model pricing table. Prompt caching multipliers apply identically. A web search triggered inside a session costs the standard $10 per 1,000 searches. Session runtime is $0.08 per session-hour, and it accrues only while the status of the session is running.

Two Messages API modifiers do not apply to a Managed Agents session. The Batch API discount does not apply, because sessions are stateful and interactive and there is no batch mode. Cloud platform pricing does not apply, because Claude Managed Agents is not available on partner-operated cloud platforms. Session runtime also replaces the code execution container-hour billing model, so you are not separately billed for container hours on top of session runtime.

Runtime is measured to the millisecond. It accrues only while the status of the session is running. Time in the idle, rescheduling or terminated status does not count toward runtime. In the idle status the session waits for your next message or for a tool confirmation.

On Claude Platform on AWS, session token and runtime charges convert to Claude Consumption Units at the standard rate.

Session runtime and container hours

The pricing page says that the code execution tool is billed by execution time when it is used without web search or web fetch. It gives each organization 1,550 free hours per month. Usage above that is $0.05 per hour, per container. In Claude Managed Agents, session runtime replaces this container-hour billing model. You are not separately billed for container hours on top of session runtime.

Frequently asked questions

How much does a Claude Managed Agents session cost per hour?

Session runtime is $0.08 per session-hour, and it accrues only while the status of the session is running. Tokens are billed in addition, at the model prices. Thirty minutes in the running status is $0.04 of runtime (0.5 x $0.08, a KickLLM calculation).

Do prompt caching and web search apply inside a Managed Agents session?

Yes. Prompt caching multipliers apply identically, and a web search triggered inside a session costs the standard $10 per 1,000 searches. The Batch API discount and cloud platform pricing do not apply to Managed Agents sessions.

Is idle time billed as session runtime?

No. The pricing page says that time in the idle, rescheduling or terminated status does not count toward runtime. Runtime is measured to the millisecond, in the running status only.

Is Claude Managed Agents billed for container hours?

No. Session runtime replaces the code execution container-hour billing model. You are not separately billed for container hours on top of session runtime.
