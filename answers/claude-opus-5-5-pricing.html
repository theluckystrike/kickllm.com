Claude Opus 5.5 pricing, $4 in and $20 out per 1M tokens

Anthropic says Claude Opus 5.5 is built for long-running agentic coding and knowledge work. It costs $4 per 1M input tokens and $20 per 1M output tokens, with a 1,000,000-token context window and 128,000-token max output. This page gives the official price grid, the Batch API rates at half price, the cache prices (cache hits are only 5% of the base input price on Opus 5.5), the fast-mode premium prices, and a calculator for estimating your workload cost.

By Michael Lip · Updated 2026-10-29

Snapshot date: 29 October 2026. Each Anthropic list price on this page (USD per 1M tokens) is from the Claude pricing page, fetched that day. The worked examples, the calculator results and the Batch API cache rates are KickLLM calculations from those list prices. Limits, the release date and the model ID are from the Claude Opus 5.5 overview and the What's new in Claude Opus 5.5 page. Prices can change without notice.

Claude Opus 5.5 was released on September 22, 2026. The Claude Opus 5.5 overview lists it as the latest model. Its price is flat across the entire context window: unlike Claude Haiku 5.5, there is no prompt-length step, so a 900,000-token request is billed at the same per-token rate as a 9,000-token request. Prompt caching and the Batch API discount apply at their standard rates across the full 1M context. Anthropic describes the model as built for long-running agentic coding and knowledge work. Source: Claude Opus 5.5 overview and Claude pricing, long context.

On most Claude models a cache hit costs 0.1x the base input price. On Claude Opus 5.5 (and Claude Sonnet 5.5) it costs only 0.05x, $0.20 per 1M tokens against the $4 base. After the cache write, repeated reads of a large system prompt or codebase context cost one twentieth of the uncached input price. Source: Claude pricing, prompt caching, snapshot 29 October 2026. The minimum cacheable prompt is 512 tokens. Source: Claude Opus 5.5 overview, snapshot 29 October 2026.

The Batch API gives a flat 50% discount on both input and output tokens, in exchange for asynchronous processing: $2 per 1M input and $10 per 1M output on Opus 5.5, against $2.50 / $12.50 on the older Opus 5. Prompt caching multipliers stack with the batch discount, and the batch rates apply across the full 1M context window with no long-prompt step. Fast mode is not available with the Batch API. Source: Claude pricing, batch processing, snapshot 29 October 2026.

Fast mode gives significantly faster output at a 2x premium on both input and output. On Opus 5.5 that is $8 / $40 per 1M tokens. Fast mode pricing applies across the full context window and stacks with prompt caching and data-residency multipliers. It is available on the Claude API and, for Opus 5.5, on Google Cloud (Anthropic managed) and on Microsoft Foundry for deployments hosted on Azure. Fast mode on Opus 5 and Opus 4.8 is in research preview, and fast mode is not available with the Batch API. Source: Claude pricing, fast mode, snapshot 29 October 2026.

US-only inference: the Claude pricing page says that for Claude 4.6 and later models, setting inference_geo: "us" multiplies every token price (input, output, cache writes and cache reads) by 1.1. This applies on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed), and to US Data Zone Standard deployments in Microsoft Foundry. Amazon Bedrock and Claude Models on Google Cloud (Google managed) have their own regional pricing. Source: Claude pricing, data residency, snapshot 29 October 2026.

Worked cost examples

KickLLM calculations at official snapshot rates

Cached agent loop. A coding agent sends the same 50,000-token codebase context on each of 20 turns and generates 4,000 output tokens per turn. Turn 1 writes the context to a 1-hour cache (50,000 × $8/1M = $0.40) and generates the output (4,000 × $20/1M = $0.08), so turn 1 costs $0.48. Turns 2 to 20 read it from cache: 19 × (50,000 × $0.20/1M + 4,000 × $20/1M) = 19 × ($0.01 + $0.08) = $1.71. The 20 turns cost $2.19 with caching. The same 20 turns uncached cost 20 × (50,000 × $4/1M + 4,000 × $20/1M) = 20 × $0.28 = $5.60. The cached loop costs about 39% of the uncached loop.

Large-document analysis. One request with a 900,000-token prompt and 8,000 output tokens, standard API, no caching: 900,000 × $4/1M + 8,000 × $20/1M = $3.60 + $0.16 = $3.76. There is no long-context premium on Opus 5.5. The per-token rate is identical for a 9,000-token prompt. On the Batch API the same request costs half: $1.88.

Batch backlog. Summarizing 10,000 documents, 3,000 input and 1,000 output tokens each, Batch API: 10,000 × (3,000 × $2/1M + 1,000 × $10/1M) = 10,000 × $0.016 = $160. The same workload at standard rates costs $320.

Managed Agents worked example (built-in check). The Claude pricing page documents a Managed Agents example: 50,000 input tokens and 15,000 output tokens. At Opus 5.5 standard rates the token part is 50,000 × $4/1M + 15,000 × $20/1M = $0.20 + $0.30 = $0.50, the sum of the source's two token lines (the source total of $0.58 USD adds $0.08 of session runtime). With 40,000 of the input as cache reads: 10,000 × $4/1M + 40,000 × $0.20/1M + 15,000 × $20/1M = $0.04 + $0.008 + $0.30 = $0.348, the sum of the source's three token lines (the source total of $0.428 USD adds $0.08 of session runtime). The same 50,000-in/15,000-out request on Opus 5 ($5/$25) costs $0.625. Other checks: the same request at fast mode is $1.00 (2x); Batch API token totals of 1,000,000 input and 200,000 output, summed over several requests, cost $4.00 ($8.00 at standard rates); with US-only 1.1x the 50,000/15,000 request is $0.55.

Cache break-even. A cache read costs 0.05x the base input price, so a cached token that is read again costs one twentieth of an uncached token. A 5-minute cache write costs 1.25x and pays for itself after 1 cache read (1.25 + 0.05 = 1.30 against 2.00 uncached). A 1-hour cache write costs 2x and pays for itself after 2 cache reads (2 + 0.10 = 2.10 against 3.00 uncached; after 1 read it is 2.05 against 2.00). Source: Claude pricing, prompt caching, fetched 29 October 2026.

Opus 5.5 is 20% cheaper than Opus 5 and Opus 4.8 on base input and output, and its cache hits cost $0.20 per 1M tokens against $0.50 on the older models, a 60% cut. Anthropic describes Opus 5.5 as built for long-running agentic coding and knowledge work. In percent, the cut on cache reads (60%) is larger than the cut on uncached input (20%). A 1-hour cache write costs 2x and pays off after 2 cache reads on both models (Opus 5.5 2 + 0.10 = 2.10 against 3.00, Opus 5 2 + 0.20 = 2.20 against 3.00). Adaptive thinking is always on in Opus 5.5 and cannot be turned off; you steer depth with the effort parameter, which defaults to medium. The synchronous max output is 128k tokens; on the Message Batches API, Opus 5.5 supports up to 300k output tokens with the output-300k-2026-03-24 beta header. The model ID is claude-opus-5-5 on the Claude API, Microsoft Foundry, Claude Platform on AWS and both Google Cloud variants, and anthropic.claude-opus-5-5 on Amazon Bedrock. Retirement is listed as not sooner than September 22, 2027. Source: Claude Opus 5.5 overview and What's new in Claude Opus 5.5, snapshot 29 October 2026.

Where these numbers come from

Calculator formula, per request. Cost = (uncached input × input rate + cache reads × cache read rate + 5-minute writes × 5-minute write rate + 1-hour writes × 1-hour write rate + output × output rate) / 1,000,000. Standard rates are $4, $0.20, $5, $8 and $20. Batch rates are $2 and $10 for input and output, and half of each cache rate. Fast mode rates are $8 and $40. US-only multiplies the total by 1.1. Workload total = cost per request × requests. The Opus 5 line uses the same formula with the Opus 5 standard rates $5, $0.50, $6.25, $10 and $25. The Batch line and the standard line use the same token counts at the other rate set.

The main sources, all fetched as text on 29 October 2026, are the Claude pricing page, which gives the base price grid, the cache write and hit lines (including the 0.05x Opus 5.5 cache-hit rate), the Batch prices, the fast-mode prices, the data residency multiplier and the long-context rule; and the model pages, the Claude Opus 5.5 overview, which gives the context window, max output, release and retirement dates and the platform model IDs, and What's new in Claude Opus 5.5, which confirms the $4 / $20 price and the breaking changes. The comparison table also uses the Claude Opus 5 overview and the Claude Opus 4.8 overview (context window and max output), and the fast mode status is from the Fast mode page. All were fetched as text on 29 October 2026.
