FAQ

How much does Qwen cost per token?

Across the 53 live Qwen models, the median is $0.2 per 1M input and $1.12 per 1M output. Cheapest input is $0.03, priciest output is $12.00.

Which Qwen model is cheapest?

Qwen3.7 Flash at $0.03 input / $0.13 output per 1M tokens.

Is Qwen cheaper than GPT-4o Mini?

At the budget tier, yes — several Qwen models cost less per input token with larger context windows. GPT-4o Mini still wins on ecosystem maturity and tooling.
