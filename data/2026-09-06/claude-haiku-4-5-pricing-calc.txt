  cache hits   = 1,350,000/1M x $0.10 = $0.14
  cache misses = 150,000/1M x $1.00 (base input) = $0.15
  never cached = 500,000/1M x $1.00 = $0.50
  output       = $2.50
  cache: daily total = $3.29; 30 days = $98.55
  saving vs no cache over 30 days = $36.45 (27.0%)
  note: if every miss is re-written as a 5m cache write at $1.25 instead of $1.00, add $0.04/day = $1.12/30 days, total $99.68
  note: a single one-time 5m write of a 1,500,000 token prefix = $1.88
